## Fundamentos da Web
- [[DOM]]: Representação em árvore de objetos dos elementos HTML construída e manipulada no navegador.
## Ecossistema React
- [[React]]: Biblioteca declarativa e não-opinativa para construção de interfaces de usuário baseadas em componentes.
- [[JSX]]: Extensão de sintaxe semelhante ao HTML para descrever elementos de UI em JavaScript.
- [[Next.js]]: Framework React full stack que fornece estrutura e configurações prontas para aplicações web.
